# Al-Ayasrah Academic Services Office
## مكتب العياصرة للخدمات الطلابية

A bilingual (Arabic / English) full-stack web platform for an academic support and consulting office. Visitors can browse services and submit service requests. Admins manage requests and services through a protected dashboard.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 14, TypeScript, Tailwind CSS, next-intl |
| Backend | Node.js, Express, TypeScript |
| Database | PostgreSQL |
| Auth | JWT + bcrypt |
| Tooling | Docker, Docker Compose, Postman, Git |
